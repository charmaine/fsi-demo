# WealthView Pro - FSI Portfolio Demo

A portfolio management demo application built for showcasing financial services UI patterns.

## Getting Started

```bash
npm install
npm run dev
```

The app runs at http://localhost:5173

## Features

- Portfolio overview with real-time summary cards
- Holdings management with sortable tables
- Performance tracking with Chart.js visualizations
- Asset allocation breakdown
- Transaction history
- Watchlist management
- Market indices and sector performance

## Tech Stack

- Vite
- Vanilla JavaScript
- Chart.js

## Project Structure

```
├── index.html      # Main HTML with app layout

├── style.css       # Styling
```
